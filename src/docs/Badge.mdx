# Badge

Compact status label. In the Tabs system it usually appears in a Tab’s `slots.end`. Resolved `variant` / `size` are exposed as `data-variant` / `data-size` for host CSS. Composition, imports, and Badge typography tokens (`--font-size-body-sm`, `--line-height-body-sm`): [Tabs overview](?path=/docs/docs-tabs-overview--docs).

## Root element

Internally a `<span>`, so you can pass native span props (`id`, `className`, `style`, `aria-*`, …) and they land on that root.

`data-variant` and `data-size` are set from the `variant` / `size` props — values you pass for those attributes are overwritten.

# TabPanel

Panel shown when `value` matches the active tab. Always render under `ActiveTabContextProvider`. For imports, keyboard, and the system entry point, see [Tabs overview](?path=/docs/docs-tabs-overview--docs).

Inactive panels set the HTML `hidden` attribute (native hide; no `aria-hidden`).

## Composition

Provider + `Tabs` + `TabPanel` with WAI-ARIA linkage (`aria-label` on the list, tab `id` / `aria-controls`, panel `id` / `aria-labelledby`):

<Canvas of={TabPanelStories.Composition} />

Throws `TabPanel must be used within an ActiveTabContextProvider.` if rendered outside the provider.

## Root element

Internally a `<section role="tabpanel">`, so you can pass native section props (`id`, `className`, `aria-labelledby`, …) and they land on that root.

`value` is not a DOM attribute (it matches against active-tab context). Visibility is driven by the HTML `hidden` attribute from that match.

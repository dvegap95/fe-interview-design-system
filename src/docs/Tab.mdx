# Tab

Single tab control for `Tabs` / `ManagedTabs`. Selection normally comes from active-tab context. Prefer not to pass `selected` while also participating in that context (it forces appearance and can conflict). System contracts: [Tabs overview](?path=/docs/docs-tabs-overview--docs).

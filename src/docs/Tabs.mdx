# Tabs / ManagedTabs

This page documents **`ManagedTabs`** (selection context + visual tablist). For panels, full composition, imports, and keyboard/a11y contracts, start at [Tabs overview](?path=/docs/docs-tabs-overview--docs).

`ManagedTabs` / `Tabs` are for the **tab list** only. For panels, compose `ActiveTabContextProvider` + `Tabs` + `TabPanel` yourself.

Import the presentational list as `Tabs` when you already have (or need) `ActiveTabContextProvider`; use `ManagedTabs` only when you want a self-contained selectable list with no sibling panels under that provider.

> **Warning:** Do not nest `ManagedTabs` inside an existing `ActiveTabContextProvider` expecting shared selection — it creates its own provider and will not inherit the outer active-tab `value` context.

## Overflow

`Tabs` does not apply `overflow-x` itself — a scrollport would clip tab `:focus-visible` outlines, so the host owns overflow (and any padding that keeps focus chrome visible) via `className`. This story uses that pattern plus `autoScrollBehavior="smooth"` so the selected tab scrolls into view. Default `autoScrollBehavior` is `"none"` (opt-in). Rationale and host CSS: [Tabs overview — Overflow](?path=/docs/docs-tabs-overview--docs#overflow).

# Tabs

This page documents **`ManagedTabs`** (selection context + visual tablist). For panels, full composition, imports, and keyboard/a11y contracts, start at [Tabs overview](?path=/docs/docs-tabs-overview--docs).

Import the presentational list as `Tabs` when you compose with `ActiveTabContextProvider` yourself; use `ManagedTabs` when you only need a selectable tablist.

## Overflow

When `autoScrollBehavior` is not `"none"`, the selected tab scrolls into view in an overflowing list. The value is passed to `scrollIntoView` as `behavior` (`auto` / `smooth` / `instant`).
